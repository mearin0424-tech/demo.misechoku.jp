# 【重要】CSSの反映について（開発・モック移行期間中）

現在、本環境では Vite のビルドプロセスをバイパスしてモック表示を優先しています。
そのため、**このディレクトリ (`resources/js/`) のファイルを修正しても、画面には反映されません。**

## 反映手順
修正が必要な場合は、以下のディレクトリにある同名ファイルを編集するか、コピーしてください。
`public/build/assets/js/`

## 理由
Viteビルド環境（npm run build）が未整備なため、`public/build/manifest.json` を手動更新し、
上記ディレクトリのファイルを直接参照させています。

※環境構築完了後、この運用は廃止予定です。
